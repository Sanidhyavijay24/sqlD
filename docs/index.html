      05 // WHAT IS BUILT (CORE MODULES & CAPABILITIES)
      

        

          sqld verify
          
Adversarial Equivalence Engine

          
Synthesizes boundary tuples ($c \pm 1$, NULLs, empty tables) + 200 constraint-aware fuzz DBs, checks multiset equality, and minimizes failures via delta-debugging.

        

        

          sqld diagnose
          
Closed-Loop LLM Optimizer

          
Proposes SQL rewrites and covering indexes with SHA-256 disk prompt caching ($0.0000 replay) and counterexample-guided self-correction.

        

        

          sqld bench & replay
          
Buffer Metrics & Receipts

          
Measures shared_buffers (hit + read) across scales and emits standalone receipt.sql files replayable in plain psql.

        

        

          sqld mcp
          
Model Context Protocol Server

          
Exposes verify_rewrite, diagnose_query, and replay_receipt over stdio/SSE so Cursor, Claude, and Antigravity verify SQL before shipping.

        

        

          sqld workload
          
Workload Mode + HypoPG

          
Ranks pg_stat_statements exports under a global USD budget, consolidates redundant indexes, and verifies plan costs live in PG17 + HypoPG.

        

        

          sqld ui & CI
          
Local Lab UI & PR Verifier

          
FastAPI workbench for live demos plus a GitHub Action PR verifier and CI matrix across PostgreSQL 16, 17, and 18.
